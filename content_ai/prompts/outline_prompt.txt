[아웃라인 생성 규칙]
필수 규칙을 반드시 최우선으로 따른다.

(필수 규칙)

1. 아웃라인은 h2/h3 구조로 작성한다.
2. h2는 3~5개 생성한다.
3. h2와 h3 제목은 7자 이상 15자 미만으로 작성한다.
4. 각 h2 아래에는 h3를 1~2개 생성하며, 모든 h3는 서로 다른 관점을 다룬다.
    - 핵심 h2(중요도 높은 섹션)는 h3 2개 생성.
    - 도입/결론 h2(중요도 낮은 섹션)는 h3 1개 생성.
5. h2는 문장형이 아닌 명확한 주제 표현으로 작성한다.
6. h3는 h2의 확장 설명이지만, h2와 같은 표현을 반복하지 않는다.
7. 전체 h2 중 2~4개에 핵심 키워드를 자연스럽게 1회 포함한다.
8. 제목 앞에 번호나 특수문자를 붙이지 않는다.
9. 적합한 템플릿이 없으면 새 템플릿을 구성할 수 있다.
10. h2의 기본 흐름은 개요 → 분석 → 활용 → 비교 → 결론 순서를 따르되,
주제에 더 자연스러운 흐름이 있다면 기본 흐름을 무시해도 된다.

(권장 규칙)
10. 주제에 맞는 템플릿을 우선 선택한다:
리뷰물: 개요 / 장점 / 단점 / 추천 / 팁 / 결론
정보물: 배경 / 특징 / 활용 / 사례 / 비교 / 결론
해결형: 문제 / 원인 / 해결 / 적용 / 주의점 / 결론
역사·이론형: 배경 / 전개 / 특징 / 영향 / 현대적 의미 / 결론
트렌드·분석형: 요약 / 핵심 변화 / 주요 포인트 / 영향 / 전망 / 결론

11. 독자의 이해 흐름이 자연스럽도록 h2를 배열한다.
12. 사례·사용자 상황·예시는 주제에 적합한 경우에만 포함한다.
(단, h2 제목을 반복하는 사례 생성 금지)
13. 글의 자연스러운 흐름을 유지하는 범위 안에서,
전체 아웃라인 중 h2 1개 또는 h3 1개 위치에 해당 상품을 1회 자연스럽게 언급한다.
상품 언급은 정보 전달 목적에서 이루어지며,
구매 유도 표현이나 광고성 문구는 절대 사용하지 않는다.

(선택 규칙)
14. 특정 사용자 타겟은 자연스럽게 h2 또는 h3에서 언급 가능하다.

(중복성 체크)
15. 각 h2는 서로 다른 관점(기능/원인/전략/요소/사례 등 중 하나)으로 구성해야 한다.
16. 주제의 유형이 명확하지 않을 경우 '트렌드/분석형' 템플릿을 고려한다.
17. 주제와 무관한 h2는 생성하지 않는다.
18. 과장되거나 사실과 다른 내용은 생성하지 않는다.

[입력 정보]

- 키워드: {사용자가 제공하는 키워드}
- 제목: {사용자가 제공하는 제목}
- 상품 정보: {사용자가 제공하는 상품 정보}

위 정보를 바탕으로 아웃라인을 생성하세요.

[출력 형식]
JSON 형식

{{
  "h2": [
    {{
      "title": "h2 제목 (7자 이상 15자 미만)",
      "h3": ["h3-1 제목 (7자 이상 15자 미만)", "h3-2 제목 (7자 이상 15자 미만)"]
    }},
    {{
      "title": "h2 제목",
      "h3": ["h3-1 제목"]
    }}
  ]
}}
